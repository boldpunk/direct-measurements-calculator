# Логотипы брендов для КП

Запасные логотипы, которые подставляются в коммерческое предложение, если у
бренда не загружен свой логотип (Склад → Справочники → Бренды → «Логотип»).

Имя файла — это название бренда, из которого оставлены только латинские буквы
и цифры в нижнем регистре. Так «BLUM», «Blum» и «Blum — фурнитура» одинаково
находят `blum.png`, а «SPS - Услуга» → `sps.png`.

Чтобы добавить бренд: положите сюда PNG (PDFKit понимает только PNG и JPEG —
SVG и WEBP надо конвертировать заранее), обрезанный по краям, шириной до
~600 px.

Папка лежит в `public/`, поэтому те же файлы отдаются и фронтенду
(`/brand-logos/blum.png`), и рендереру PDF на сервере.
